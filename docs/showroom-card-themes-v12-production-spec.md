# 카드 테마 V12 커플링 제작 명세

## 공통 구조

- 최종 헤더 에셋은 1680×400 WebP다.
- 원화를 늘이거나 찌그러뜨리지 않고 처음부터 4.2:1 헤더 스트립으로 제작한다.
- 좌측 22%는 별도 초상화·초상화 프레임이 올라오는 안전영역으로 비운다.
- 중앙 좌측 상단은 칭호·이름, 하단은 오늘의 한마디 영역이다.
- 우측 상단은 트로피 전시 영역으로 별도 박스를 그리지 않는다.
- 우측 하단은 최고·최저·현재 수치를 위한 동일 크기 3칸을 둔다.
- 체중 칸은 빨강·초록·파랑 고정색을 사용하지 않고 테마 재질과 색을 따른다.
- 이미지의 모든 장식은 헤더 경계 안에 들어가야 하며 상단 돌출과 잘림을 허용하지 않는다.
- 신규 항목은 개별 승인 전 구매·저장할 수 없는 테스트 전용이다.

## 가격과 승인

- 희귀 예정가: 880포인트
- 영웅 예정가: 1,430포인트
- 신화 예정가: 2,200포인트

승인 시에만 `testOnly:false`, `purchasable:true`, `persistable:true`로 전환한다. 신규 카드 테마는 기존 20종을 대체하거나 기존 보유권을 변경하지 않는다.
