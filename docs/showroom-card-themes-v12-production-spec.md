# 카드 테마 V12 제작 명세

## 확정 구조

- 최종 헤더 자산은 모두 `1680×400`(4.2:1) 규격으로 제작한다.
- 카드 테마 이미지는 헤더 전체의 배경과 외곽 프레임만 담당한다.
- 이미지 내부에 칭호·이름, 오늘의 한마디, 트로피, 최고·최저·현재용 상자를 미리 그리지 않는다.
- 실제 텍스트와 수치는 DOM/CSS로 배치하며, 테마의 문양과 장식이 글자를 침범하지 않도록 중앙 내부 명암을 낮춘다.
- 초상화 영역은 프레임 이미지에 포함하지 않는다. 별도 초상화 프레임이 가장 높은 레이어에 표시된다.
- 최고·최저·현재는 빨강·초록·파랑 고정색을 쓰지 않고 테마별 패널·테두리·글로우 변수를 사용한다.
- 트로피는 별도 배경 칸 없이 우측 상단에 정렬하며, 테마별 글로우만 적용한다.
- 외곽 장식은 헤더 경계 안에 완전히 들어가야 하며 상단 돌출, 하단 잘림, 마젠타 가이드 잔여를 허용하지 않는다.
- 신규 항목은 기존 항목을 대체하지 않고 추가한다.
- 승인 전 신규 항목은 `testOnly: true`, `purchasable: false`, `persistable: false`를 유지한다.
