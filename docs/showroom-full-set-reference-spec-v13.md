# 쇼룸 풀세트 V13 레퍼런스·제작 명세

## 원칙

- 세트 프리셋은 7범주 중 일부가 비어 있어도 선택할 수 있다. 빈 범주는 `null`, 즉 기본값으로 미리보기한다.
- 기존 상품을 대체하지 않고 신규 ID로 추가한다. 단, 대표님이 교체를 지시한 `pe_u_blue_bear_slugger`는 보유권 보존을 위해 ID를 유지하고 이미지만 교체한다.
- 배경 이미지는 그래프 스킨 `16:9`, 카드 테마 `4.2:1`, 프로필 초상화·프레임은 `1:1`을 엄수한다.
- 그래프 스킨은 데이터 영역의 가독성을 위해 중앙 대비를 낮추고, 주요 조형은 외곽과 원근 배경에 둔다.
- 카드 테마는 초상화 자리, 칭호·이름·한마디, 트로피, 최고·최저·현재의 안전영역을 침범하지 않는다.
- 고급은 KBO·일상, 영웅은 Marvel 계열, 신화는 Warcraft 계열의 시각 밀도와 마감 차이를 유지한다.

  - https://worldofwarcraft.blizzard.com/en-us/media/comic/reunion
- 밴시 여왕: Blizzard의 Sylvanas 페이지. 창백한 언데드 피부, 붉은 두건, 자주·흑색 갑주, 뼈 장식 활, 밴시·발키르·지배 사슬.
  - https://worldofwarcraft.blizzard.com/en-us/news/23665016/warcraft-sylvanas-now-available
  - https://worldofwarcraft.blizzard.com/en-us/news/21964422/watch-warbringers-sylvanas
- 여왕: Blizzard의 Nazjatar 및 Warbringers: Azshara. 다완 나가 여왕, 짙은 청록 피부, 산호 왕관, 적금 장신구, 심해 궁전·생물광·해일.
  - https://worldofwarcraft.blizzard.com/en-us/news/23034748
  - https://worldofwarcraft.blizzard.com/en-us/news/22358468/warbringers-azshara
- 수호자: 카라잔의 까마귀, 보랏빛 비전, 황금 천문기구, 시간 왜곡, 화염 고리를 핵심 상징으로 사용한다.
