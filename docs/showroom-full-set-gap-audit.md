## 프리셋 무결성

- `SHOWROOM_CANONICAL_SET_ITEMS`가 각 세트의 공식 7개 구성품을 고정한다.
- 같은 모티브·같은 범주에 대체 아이템이 추가되어도 선언 순서로 프리셋이 바뀌지 않는다.
- 향후 세트에 빈 범주가 생기면 해당 범주는 기본값으로 미리보기한다.
- 사용자가 섞어 만든 조합은 공식 세트와 별도로 최대 5개 저장한다.

## 퇴역 정책

- 동반자 원본 모듈과 파일은 역사 보존용으로 남길 수 있지만 활성 카탈로그,
  구매, 관리자 지급, 세트, 장착 검증에는 절대 포함하지 않는다.
- 퇴역 아이템 ID는 다른 새 아이템으로 자동 치환하지 않는다.
- 장비 모티브 초상화 `pe_r_roaring_tiger_general`은 활성 카탈로그에서 제외한다.
