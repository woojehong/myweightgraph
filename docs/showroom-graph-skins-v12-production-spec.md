# 그래프 스킨 V12 제작 명세

## 적용 원칙

- 그래프 스킨은 `우리 그래프`의 메인 체중 그래프 16:9 영역에만 적용한다.
- 모든 결과물은 1536×864 WebP이며 빈틈 없이 `cover`된다.
- 중앙 안전영역은 `x 12% / y 15% / width 76% / height 70%`다.
- 중앙에는 성, 인물, 로고, 문구 같은 강한 초점을 배치하지 않는다.
- 이야기와 장식은 가장자리와 모서리에서 읽히게 하고 그래프 선·축·마커의 가독성을 우선한다.
- 신규 20종은 승인 전 테스트 전용이다. 미리보기는 가능하지만 구매와 최종 저장은 불가능하다.
- 예정 가격은 고급 600, 희귀 1,200, 영웅 1,950, 신화 3,000 포인트다.

## 기존 스킨 승격

기존 ID와 보유권을 유지한 채 아래 세 스킨의 등급만 신화로 승격한다.

- `gs_v4_rare_02` 폭풍왕국
- `gs_v4_epic_01` 은빛달 궁정
- `gs_v4_epic_03` 심해 여왕 궁전

이미 보유한 계정에는 추가 비용·회수·대체를 적용하지 않는다.

### 고급

1. 남색 곰의 더그아웃
2. 쌍별 야간구장
3. 호랑이 불펜
4. 주황 독수리 스카이박스
5. 새벽 한강 러닝트랙

### 희귀

1. 와룡의 팔진대
2. 적벽의 화선
3. 월아청룡 사당
4. 백마은창 관문
5. 황실 옥새 서고

### 영웅

1. 천둥왕자의 천문교
2. 진홍 마녀의 현실정원
3. 거미차원의 야경
4. 비전술사의 거울성소
5. 흑진동 왕국의 심장

4. 파도현자의 해상요새
5. 달의 여사제 성역

## 승인 게이트

신규 스킨은 실제 16:9 메인 그래프에 선·축·마커를 함께 겹쳐 본 뒤 개별 승인한다. 승인된 항목만 `testOnly:false`, `purchasable:true`, `persistable:true`로 전환하며 예정 가격을 실제 가격으로 확정한다.
