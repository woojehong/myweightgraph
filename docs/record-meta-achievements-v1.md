# 기록 중심 메타 업적 v1

## 원칙

- 체중 감량량, 목표 체중 도달, 주간·월간 감량 폭은 업적 조건으로 사용하지 않는다.
- 체중·식단·물·운동 여부를 정직하게 기록하는 행위만으로 달성할 수 있다.
- 운동을 하지 않은 날도 `운동 안 함`을 명시했다면 기록으로 인정한다.
- 결식은 유효한 식단 기록이다.
- 3개월, 6개월, 1년 장기 목표를 함께 제공하되 매일 완벽한 연속 기록을 강요하지 않는다.
- 감량형 기존 업적 43종과 기존 중복 장기 업적 2종은 신규 획득 대상에서 제외한다.

## 구성

- 3개월 메타 업적 12종
- 6개월 메타 업적 10종
- 1년 메타 업적 8종
- 업적 전용 칭호 30종
- 업적 전용 유물급 트로피 12종

트로피와 칭호의 기본 연결은 `js/record-meta-rewards.js`에 정의하며, 슈퍼관리자는 관리자 화면의 `업적 ↔ 칭호·트로피 연결`에서 계정 전체에 적용할 연결을 바꿀 수 있다. 명시적으로 비워 저장하면 기본 보상도 제거된다.

## 트로피 미술 방향

현실의 유명 우승 트로피가 가진 즉시 알아볼 수 있는 실루엣을 오마주하되, 마웨그의 기록·시간·달력 상징을 결합한 독립 조형물로 제작한다. 모든 이미지는 투명 배경 512×512 WebP, 동일 시각 높이, 쇼룸 구매 불가, 업적 전용 유물급이다.

| 마웨그 트로피 | 현실 오마주 방향 | 마웨그 변형 요소 |
|---|---|---|
| 계절의 모래시계 | 클라레 저그형 주전자 컵 | 사계절 모래시계 |
| 열두 주의 나침반 | 마이스터샬레형 원형 방패 | 12주 보석과 나침반 |
| 석 달의 기록석 | 애시스 항아리형 트로피 | 세 개의 달과 기록 문양 |
| 기록의 프리즘 | 빈스 롬바르디형 기둥 | 빛을 분광하는 수정 |
| 귀환의 불사조 | UEFA 유로파리그형 역삼각 컵 | 불사조 날개와 불씨 |
| 반년 항해의 성배 | 아메리카스컵형 은제 주전자 | 항해 별자리와 모래시계 |
| 여섯 달 천문반 | 래리 오브라이언형 구체 | 달 위상과 천문 궤도 |
| 철야의 강철 수첩 | 하이즈먼형 동세 | 수첩과 펜을 든 기록자 |
| 사계절의 세계수 | FIFA 월드컵형 상승 실루엣 | 사계절 세계수 구체 |
| 황금 연감 | 스탠리컵형 적층 실루엣 | 정상의 황금 기록책 |
| 천 개 식탁의 성배 | 윔블던 신사 단식컵형 양손 컵 | 밀 이삭·접시·수저 문양 |
| 영원의 기록보관소 | MLB 커미셔너스 트로피형 방사 구조 | 깃발 대신 기록 두루마리 |

## 이미지 생성 기록

- 생성 방식: OpenAI ImageGen 기본 생성 모드, 1:1 래스터 일러스트.
- 공통 프롬프트: `single centered museum-quality fantasy sports trophy, real-world championship trophy silhouette homage, transformed with record-keeping and time symbolism, ornate gold/silver materials, no text, no logo, isolated on flat chroma-green background, crisp game collectible icon, full object visible with safe padding`.
- 개별 변형: 위 표의 오마주 실루엣과 마웨그 변형 요소를 각 프롬프트에 결합했다.
- 후처리: 크로마키 제거, 소프트 매트·디스필, 알파 경계 정리, 512×512 중앙 정렬 및 동일 시각 높이 규격화.
