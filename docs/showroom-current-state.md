# 마웨그 쇼룸 현행 운영 기준

기준일: 2026-07-29

## 활성 범주

그래프 스킨, 그래프 선, 카드 테마, 포인트 마커, 공간 효과, 트로피,
프로필 초상화, 초상화 프레임, 칭호를 운영한다. 동반자는 폐기했다.

## 소유권 출처

- 구매: `purchasedItemsV2`
- 업적: `achievementRewardItems`
- 관리자 지급: `adminGrantedItems`

동일 아이템에 여러 소유권 출처가 공존할 수 있다. 관리자 지급분 회수나 구매
환불은 해당 출처만 제거하며, 다른 출처가 남으면 아이템은 계속 보유한다.

## 구매와 환불

- 신규 구매는 구매 가격과 시각을 `catalogPurchaseLedgerV2`에 기록한다.
- 슈퍼관리자는 구매 아이템만 환불할 수 있다.
- 환불은 기록된 구매 가격을 우선 복구하며, 구형 구매처럼 원장이 없으면 현재
  카탈로그 가격을 복구한다.
- 환불 시 구매 소유권만 제거한다.
- 보유권이 완전히 사라진 장착품은 기본값으로 안전하게 복귀한다.
- 최근 환불 100건은 `catalogRefundLogV2`에 관리자 UID, 사유, 아이템, 금액과
  함께 보존한다.

## 수집 UX

- 수집 도감: 전체·범주별 수집률
- 찜하기: `showroomFavoritesV2`
- 사용자 조합: `showroomPresetsV2`, 최대 5개
- 공식 세트: canonical 7개 구성품으로 원클릭 미리보기
- 구매 완료: 최초 획득 공개 연출

## 자산 로딩

서비스워커 설치 시 앱 셸만 사전 캐시한다. 수집품 이미지는 목록이나 실제 카드에서
처음 요청할 때 네트워크 우선으로 내려받고 이후 캐시한다. 이미지 태그에는 지연 로딩과
비동기 디코딩을 사용한다.
