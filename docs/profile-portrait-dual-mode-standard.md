# 프로필 초상화 전신·상반신 제작 표준

이 문서는 향후 모든 프로필 초상화 신규 제작과 기존 자산 보정에 적용하는 고정 규격이다.

## 상품과 장착

- 초상화 한 종은 한 번만 구매한다.
- 한 상품에 `전신(full)`과 `상반신(bust)` 두 구도를 포함한다.
- 두 구도는 별도 상품이나 별도 가격으로 취급하지 않는다.
- 쇼룸에서 표시 방식을 선택하고 `최종 저장`을 눌러 공개 카드에 반영한다.
- 우리 그래프와 쇼룸의 대형 카드에는 저장된 구도를 사용한다.
- 로그인, 사용자 선택, 작은 목록 등 compact 화면에는 가독성이 높은 상반신 구도를 사용한다.

## 공통 이미지 규격

- 1:1 투명 캔버스를 사용한다.
- 배경, 원형 마스크, 프레임을 초상화 원본에 포함하지 않는다.
- 프레임과 조합했을 때 얼굴, 머리 장식, 손, 주요 무기가 부자연스럽게 가려지지 않아야 한다.
- 알파 가장자리는 캔버스 끝에 닿지 않아야 한다.
- 테마와 제작 시기가 달라도 얼굴 크기, 전신 높이, 시각 중심을 동일 규격으로 맞춘다.

## 전신 구도

- 캐릭터 전체 실루엣과 대표 장비가 읽혀야 한다.
- 주 피사체 높이는 캔버스의 `91% ± 2%`를 목표로 한다.
- 발이나 하단 의상이 바닥에 붙거나 떠 보이지 않게 한다.
- WoW 계열을 포함한 장식이 큰 판타지 캐릭터는 효과와 무기 때문에 과대하게 보이지 않도록 체감 크기를 별도 보정한다.

## 상반신 구도

- 전신 이미지를 단순 CSS 확대만 한 결과물을 최종 자산으로 사용하지 않는다.
- 얼굴과 상체가 강조되는 별도 구도로 제작한다.
- 얼굴 높이는 캔버스의 `22% ± 2%`, 어깨 폭은 `60% ± 6%`를 목표로 한다.
- 머리 위 여백은 8–12%로 유지한다.
- 목, 손목, 팔꿈치 같은 관절을 절단선으로 사용하지 않는다.

## 신규 제작 절차

1. 대표님이 지정한 모티브와 이름을 확정한다.
2. 실제 시각 레퍼런스를 조사해 얼굴, 의상, 실루엣, 대표 장비, 색 구성표를 확인한다.
3. 전신·상반신을 같은 캐릭터 디자인과 재질 표현으로 제작한다.
4. 1:1 투명 캔버스와 안전영역을 검증한다.
5. 무프레임 및 가장 두꺼운 프레임 조합을 모두 검수한다.
6. WoW, KBO, 삼국지, 마블 및 신규 테마를 서로 섞어도 크기와 렌더 밀도가 어긋나지 않는지 비교한다.

## 파일 계약

- 전신: `portrait_[character]_full.webp`
- 상반신: `portrait_[character]_bust.webp`
- 카탈로그의 동일 아이템 ID 아래 `portraitAssets.full`과 `portraitAssets.bust`로 연결한다.
- 어느 한쪽이 아직 제작되지 않은 기존 아이템은 현재 기본 자산을 임시 폴백으로 사용하되, 최종 신규 자산은 반드시 두 파일을 제공한다.

## 실패 조건

- 비율이 1:1이 아님
- 배경 또는 프레임이 초상화 파일에 합쳐짐
- 프레임 밖으로 초상 알파가 노출됨
- 얼굴, 왕관, 발, 주요 무기가 의도 없이 잘림
- 테마 간 얼굴 크기 또는 전신 높이가 허용 편차를 넘음
- 작은 화면에서 얼굴을 식별하기 어려움
- 모드 변경에 재구매가 필요하거나 소유권이 분리됨
