# 쇼룸 분류·세트 기준

쇼룸 수집품은 `보유 상태`, `등급`, `원전 카테고리`, `세트`를 서로 독립적으로 조합해 필터링한다.

## 필터 축

- 보유 상태: 전체 / 보유 / 미보유
- 등급: 일반 / 고급 / 희귀 / 영웅 / 신화 / 초월 / 전설 / 유물
- 원전 카테고리: WoW / 마블 / KBO / 삼국지 / 기타
- 보기 방식: 아이템별 / 세트별

세트는 원전 카테고리를 대체하지 않는다. 예를 들어 `리치 왕 세트`의 원전 카테고리는 계속 `WoW`다.

## 완성 대상으로 관리하는 16세트

- WoW: 리치 왕, 대제독, 배신자, 밴시 여왕, 대족장, 수호자, 여왕, 태양왕
- 마블: 강철 인간, 천둥의 신, 미국 대장, 진홍 마녀
- KBO: 철웅이, 망곰이, 럭키 & 스타, 루피

각 세트는 아래 7개 슬롯으로 완성도를 계산한다.

1. 그래프 스킨
2. 카드 테마
3. 공간 효과
4. 그래프 선
5. 프로필 초상화
6. 초상화 프레임
7. 포인트 마커

한 슬롯에 후보 아이템이 여러 개면 모두 같은 세트로 분류하되, 세트 완성도는 해당 슬롯의 존재 여부로 계산한다.

## 확정 모티브 표시명

- WoW: 리치 왕, 대제독, 배신자, 밴시 여왕, 대족장, 수호자, 여왕, 달의 여사제, 태양왕, 로고쉬, 왕자, 대지 고리회, 대흑마법사, 파괴자, 생명의 어머니
- 마블: 강철 인간, 천둥의 신, 소서러 슈프림, 진홍 마녀, 거미 인간, 흑표범, 미국 대장
- 삼국지: 와룡, 비장, 미염공, 상산
- KBO: 철웅이, 망곰이, 럭키 & 스타, 루피, 호걸이, 수리

`장비` 모티브 초상화(`pe_r_roaring_tiger_general`)는 폐기 항목이다. 사용자 카탈로그, 미리보기, 오프라인 캐시에서 제외한다.
