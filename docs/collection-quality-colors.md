# 마웨그 수집품 품질·색상 표준

확정일: 2026-07-27

이 문서는 향후 모든 수집품 범주에서 공통으로 사용할 7단계 품질 체계를 정의한다.
현재 카탈로그 전체를 즉시 마이그레이션하지 않으며, 신규 제작분부터 단계적으로 적용한다.

| 내부 키 | 표시명 | 색상 | 기준 |
|---|---|---:|---|
| `common` | 일반 | `#FFFFFF` | 흰색 |
| `uncommon` | 고급 | `#1EFF00` | 선명한 초록 |
| `rare` | 희귀 | `#0070DD` | 선명한 파랑 |
| `epic` | 영웅 | `#A335EE` | 보라 |
| `mythic` | 신화 | `#FF8000` | 주황 |
| `transcendent` | 초월 | `#FF2D2D` | 강한 적색 |
| `artifact` | 유물 | `#E6CC80` | 노란빛이 도는 고대 금색 |

## 선정 원칙

- 일반·고급·희귀·영웅·신화·유물은 MMORPG에서 검증된 품질색 계열을 우선 참고했다.
- 신화의 `#FF8000`은 강한 주황색으로, 기존 전설 계열의 시각적 위상을 계승한다.
- 초월의 `#FF2D2D`는 주황·금색과 혼동되지 않는 순적색으로 별도 정의한다.
- 유물의 `#E6CC80`은 형광 노랑이 아니라 오래된 금속과 성유물을 연상시키는 옅은 금색이다.
- 품질색은 아이템명, 품질 배지, 관리자 필터와 획득 안내에 사용한다. 원화 전체를 품질색으로 물들이지 않는다.
- 트로피는 가격과 구매 등급을 갖지 않지만, 이번 신규 12종은 제작 품질과 UI 표기를 위해 모두 `artifact`로 등록한다.
