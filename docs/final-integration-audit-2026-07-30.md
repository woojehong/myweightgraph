# 마웨그 최종 통합검수

- 30일 성실 기록 예상 수입: 2,992포인트
- 신화 그래프 스킨 가격: 3,000포인트
- 소급 포인트 지급: 오늘 포함 2일 전까지
- 3일 전 기록: 추적·업적 반영, 포인트 미지급
- 물: 1잔 이상 기록하면 해당 항목 포인트 전액
- 결식: 기록·연속 완주에는 포함, 품질 보너스·전용 업적·전용 포인트 없음
- 공식 풀세트: 16세트, 세트당 7개 구성, 총 112개 연결
- 이미지 자동검사: 140개 비율·최소 해상도·중복 검사
- 트로피: 12종, 업적 전용, 구매 불가
- 관리자: 수집품 지급·회수·환불 이력 및 업적-트로피 전체 계정 반영
- 프로필: 공용 렌더러와 웃는 기본값 사용, 관리자 구형 이모티콘 편집기 제거
