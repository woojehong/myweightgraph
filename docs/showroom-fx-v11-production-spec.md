# 마웨그 쇼룸 V11 — 그래프 선·공간 효과 전면 교체 명세

확정일: 2026-07-27

## 교체 범위

- 기존 그래프 선 32종과 공간 효과 36종은 활성 카탈로그에서 전면 폐기한다.
- 기존 ID를 신규 아이템으로 자동 치환하지 않으며 환불·보상하지 않는다.
- 신규 그래프 선 8종과 공간 효과 8종만 등록한다.
- 최초 출시는 모두 테스트 전용이며 구매·최종 저장을 차단한다.
- 적용 범위는 정확히 16:9 메인 체중 그래프뿐이다. 식단·운동 서브그래프에는 적용하지 않는다.

## 필수 안전 규칙

- 데이터 좌표를 변형하지 않는다.
- 본선은 항상 장식보다 선명하며 최저점 마커보다 아래에 놓인다.
- 공간 효과의 중앙 64%×58% 영역은 불투명 파츠를 금지한다.
- 공간 효과는 그래프 스킨보다 위, 데이터 선·눈금·마커보다 아래에 합성한다.
- `prefers-reduced-motion`에서는 대표 정지 프레임으로 고정한다.
- 탭이 숨겨지면 애니메이션을 중단한다.
- 쇼룸 상품 카드에는 정적 아이콘이 아니라 실제 축소 라이브 미리보기를 제공한다.
- 코드 기본 원·삼각형·단색 점을 완성품 파츠처럼 노출하지 않는다.
