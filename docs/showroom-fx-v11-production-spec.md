# 마웨그 쇼룸 V11 그래프 선·공간 효과 제작 명세

확정일: 2026-07-28

## 적용 범위

- 그래프 선 8종과 공간 효과 8종만 활성 카탈로그에 등록한다.
- 기존 ID는 신규 아이템으로 자동 대체하거나 소유권을 보상하지 않는다.
- 신규 16종은 대표 승인 전까지 테스트 전용이며 구매·최종 저장할 수 없다.
- 효과는 정확히 16:9 메인 체중 그래프에만 적용한다. 식단·운동 서브그래프에는 적용하지 않는다.

## 등급별 그래프 선 규칙

| 등급 | 수량 | 색상 | 움직임 | 상품 가치 |
|---|---:|---|---|---|
| 고급 | 2 | 직접 선택 | 없음 | 점선·일점쇄선처럼 선 모양을 변경 |
| 희귀 | 2 | 선택형 1, 고정형 1 | 사실상 정적 | 이중 깃결·각인·숯결 같은 정교한 고정 질감 |
| 영웅 | 2 | 테마 고정 | 명확한 동적 효과 | 전류·에너지 리본·룬 파편이 선을 따라 이동 |
| 신화 | 2 | 테마 고정 | 복합 동적 효과 | 본선·잔광·결정·파동·분리 입자가 하나의 연출로 순환 |

`colorMode: custom`인 상품에서만 쇼룸 색상 선택기를 활성화한다. `fixed` 상품은 제작된 색과 애니메이션을 하나의 완성된 상품으로 취급한다.

## 등급별 공간 효과 규칙

| 등급 | 수량 | 모션 등급 | 연출 원칙 |
|---|---:|---|---|
| 고급 | 2 | static | 외곽 조명·먹 번짐 등 정적 공간 장식 |
| 희귀 | 2 | subtle | 거의 정적으로 보이는 저속 호흡과 간헐 반응 |
| 영웅 | 2 | heroic | 다층 파티클과 흐름장, 사건 순서가 있는 강조 연출 |
| 신화 | 2 | mythic | 전후경·환경·대형 강조 연출을 함께 사용하는 최고 단계 |

공간 효과는 공통 PNG 흔들기 함수로 만들지 않는다. 각 상품이 별도의 Canvas 렌더러와 고유한 시간 구조를 가진다.

## 활성 컬렉션

| 등급 | 그래프 선 | 공간 효과 |
|---|---|---|
| 고급 | 챔피언 실밥선, 묵향 병법선 | 챔피언의 구장, 먹빛 전장 |
| 희귀 | 와룡 깃털선, 적벽 화공선 | 팔진도의 바람, 적벽의 화공 |
| 영웅 | 천둥신 전류선, 진홍 혼돈선 | 폭풍 차원, 진홍 혼돈장 |
| 신화 | 빙혼 룬검선, 황천 쌍날선 | 얼음왕관 눈보라, 검은 성소의 균열 |

## 공간 효과 연출 구성

- 폭풍 차원: 폭우 → 예고광 → 낙뢰 → 잔류 전류
- 진홍 혼돈장: 양방향 에너지 리본 + 회전 마법진 + 수정 파편
- 얼음왕관 눈보라: 3단계 깊이 눈보라 + 냉기 안개 + 룬진 + 영혼불
- 검은 성소의 균열: 개폐형 이중 균열 + 에너지 파도 + 흑요 파편 + 지옥 유성

## 가독성·성능 규칙

- 공간 효과는 데이터셋보다 아래에 그려 실제 체중선과 마커를 가리지 않는다.
- 그래프 중앙에는 보호 스크림을 적용하고 외곽에서 효과 강도를 높인다.
- `prefers-reduced-motion`에서는 모든 시간값을 고정한다.
- 숨겨진 탭에서는 애니메이션 갱신을 중단한다.
- 그래프가 여러 개일 때 프레임 예산을 자동으로 낮춘다.
- 쇼룸 미리보기와 실제 우리 그래프는 같은 렌더러를 사용한다.
